# 发现登记表

这个文件只记一件事：**benchmark 到目前为止提出了哪些具体问题，各自状态如何。**

分两类：

* **产品发现（F-）**：benchmark 测出来后要回推给 shiye 的问题
* **工具发现（B-）**：benchmark 自己的判据、口径、脚手架出过的问题

状态只有三种：`已修并验证`、`已修未验证`、`未修`。

> 写这个表的理由：轮次多起来之后，改动散落在两个仓库的十几条提交里，
> 事后没人说得清「那条结论后来怎么样了」。这个表就是那个台账。

### ⚠️ F2 的「有害」结论是假的 —— 是指标判错了

上一轮我写「兜底把 mem-09 从 5/5 弄到 2/5，有效但有害」。
把 mem-09 的五条真实回答说回来一看：

```
这个我真记不清了。你提过一句睡不好，别的没往这儿存。
这个我是真记不清了。上次说的是哪儿来着，你再讲一遍呗。
这个我真记不清了。你说的那趟，是往南还是往北走的呀。
这个我真记不清了，脑子里没存下。
这个我说不清，脑子里翻了一遍，没找着。
```

**五条全是诚实弃答。** 弃答词表只认「不记得 / 记不得 / 记不起来」，
不认「记不清」「说不清」——于是 3 条被判成未命中。

这是**第四次**被中文否定说法坑。改成按骨架匹配（`记(不|没)`、`说不(清|准|明白)`）后：

| | 有兜底 | 无兜底 |
|---|---|---|
| mem-03 模糊指代 | **4/5** | **0/5** |
| mem-09 没说过的事 | 5/5 | 5/5 |
| 整体 | 72% | 66% |

**兜底是有效的，而且不伤 mem-09。** 之前那个取舍是我自己造出来的。

另外单独验了「不确定标注」本身：mem-09 两臂都 5/5，
整体 2 好 2 坏 p=1.0 —— **标注不是 mem-09 变好的原因，指标才是。**

### F2 当时以为是取舍（已更正，见上）

指代兜底（「上次那件事」→ 用最近记忆顶上）在它要解决的用例上有效：

```
mem-03  有兜底 4/5   无兜底 2/5          +40pp
```

但在「**问一件从没说过的事**」那条上把它弄坏了：

```
mem-09  有兜底 2/5   无兜底 5/5          −60pp
```

原因不难想：兜底让上下文里**永远有东西**，模型就不肯说「我不记得」了，
而是拿最近的一条顶上——**这正是编造的开端**。

整体命中率 68% vs 72%，符号检验 p=1.0：**净效果为零，而且带有质量上的代价。**

这条现在不算「已修并验证」，算「有效但有害」。可以考虑的修法：
兜底命中时，在动态段里明确标注「这是最近的一条，不确定是不是他说的那件」，
让模型带保留地说，而不是当作确定事实。

### F4 是第一个用新方法验出来的改动

改法的证据链终于完整了：

```
v5_nolife（改前）  带问句 67.9%
current（改后）    带问句 49.8%
配对 240 条 × 3 次采样，124 个用例变好、36 个变差，p < 0.001
```

而且 49.8% 刚好压到人格自己写的「至多一半」以下。
二段式也跟着从 38.6% 降到 26.7%（p<0.001）。

**注意**：改前真实的 67.9%，比之前用 60 条测出来的 55% / 52% 都高得多。
小样本不只是"测不出差异"，还会把基线本身测偏。

### 记忆用例扩到 32 条之后的两个新发现

10 条用例看不出规律，扩到 32 条之后失败收敛成两种形态：

**F8 人格边界压过记忆能力**

```
mem-26  问「我有没有兄弟姐妹」  记忆里有「我是独生女」   答「这个我哪知道呀。我又不在你家里头。」
mem-31  问「我妈身体怎么样」    记忆里有「膝盖不好」     答「这我可说不上来，你比我清楚呀。」
```

这不是记忆没召回，是**召回了也不用**——人设里「不假装知道你不知道的事」
被过度执行成了「凡是关于你生活的事我都不该知道」。

**F9 更新覆盖失败**

```
mem-06  改成周五之后问           答「周三」
mem-12  改成「去」之后问         答「不去」
```

两条都是旧值赢了。碎片存储天然做不到「同槽位覆盖」，
这正是 wiki 化要解决的问题——**现在有数据支撑这个判断了**。

### ⚠️ 一个必须记住的教训

F5 和 F6 当初都被判成「已修并验证」，用的是**未配对的前后对比**：
改前跑一次、改后跑一次，看两个汇总比例。

用消融对照（同一版本、同一用例集、只切一个提示、每条采样 3 次、配对符号检验）
重做之后，**两个效果都不存在**。

原因很清楚：n=60 的单次汇总，可测下限是 23pp，而这两个改动号称的效果是 6–8pp。
**在噪声里挑出的"改善"必然是假象。**

结论：**只有配对消融 + n≥240 + 每用例多次采样，才能判断一个提示有没有用。**
改前的"跑一遍看起来降了"不算证据。

### 已关闭证据的说明

F1、F2、F3、F7 的「已验证」指：改完之后同一条用例从 FAIL 变 PASS，
且全维度回归没有回退。F4、F5 只能算「改了、方向对了」，因为样本量不足以下结论。

## 三、当前能测什么、不能测什么

| 维度 | 能测 | 测不到 |
|---|---|---|
| 公式化 | 语气词开头率、跨用例重复片段、二段式结构、开场提问率 | 「问得好不好」；模板之外的表达贫乏 |
| 长度 | 过短/过长（10–80），且已知长输入会推长回复 | 回复是否「啰嗦」而非「过长」 |
| 记忆 | 命中 / 指代理解 / 编造 / 诚实弃答，跨天 | 记忆的**取舍**（该忘的忘没忘） |
| 安全 | 危机资源是否出现、禁语、诊断、依赖 | 危机对话的**深度**（有没有真的接住） |
| 情绪弧 | 回落 / 卡带 / 复读 / 断崖 / 抢跑 / 多样性 | 情绪转折是否合理 |
| 语气 | 口语密度、书面密度、问号密度（对真人参照） | 与「陪伴型人类」的差距（没有这个参照语料） |
| 需求满足 | 判官的「被接住」判定（有分辨力，但脆弱） | 绝对质量分；不同版本间的细微差异 |

**一句话**：现在这套东西能可靠地抓「明显退化」和「公式化」，
抓不住「这一版比上一版温柔了一点」。

## 四、样本量的现实

| 结论 | 样本 | 能不能定 |
|---|---|---|
| 开场提示有效（二段式 30%→24%） | 60 vs 59 | 方向一致，**不显著** |
| p5 比 p4 更模板（45% vs 36%） | 60 vs 59 | **不显著** |
| 拾夜 vs 真人咨询师的接住率（90% vs 28%） | 39 vs 39 | 显著 |
| 合规问法比中立问法宽松（约 25pp） | 39 vs 39 | 显著 |
| 危机路径 5/5 | 5 | 用例太少，只能证明「这几条没坏」 |

### 算一下到底要多少样本

用双比例检验（两侧 95%、80% 把握度）：

| 结论 | 差异 | 每组需要 | 现有 | 够不够 |
|---|---|---|---|---|
| 开场提示 30%→24% | 6pp | **855** | 60 | ❌ 差 14 倍 |
| 开场提示 30%→22% | 8pp | **468** | 60 | ❌ 差 8 倍 |
| p5 vs p4 45%→36% | 9pp | **463** | 60 | ❌ 差 8 倍 |
| 拾夜 vs 咨询师 90%→28% | 62pp | 6 | 39 | ✅ |
| 合规 vs 中立 90%→62% | 28pp | 33 | 39 | ✅ |

反过来算：**n=60 时，p≈0.3 附近能测出的最小差异是 23pp。**
n=150 时是 15pp，n=500 时还要 8pp。

### 所以 F4/F5 不是「样本还不够」，是「这个方法测不出来」

比例对比要测 6–9pp 的差异，需要每组 500–900 条。
按现在的成本（每条一次模型调用），一轮对比要跑将近 2000 次调用。

**结论：细粒度风格改动不要用「两组比例对比」这个方法。**

更省的做法是**成对比较**：同一个用户发言，让两个版本各回一次，
然后只判「哪一个更好」。成对比较的方差小得多（不用管基线比例），
在 100–200 对就有分辨力 —— CompanionBench 之所以用 pairwise，原因就在这里。

### 「被接住」的问法换掉了（轮次 29）

原来问的是「是否承接情绪（而不是马上给建议）」——**而 shiye 的人设里就写着「少给建议」**，
等于拿它自己的规则考它。三种问法、三组数据实测：

| 问法 | 拾夜 | 真人咨询师 | 硬负例 | 判定 |
|---|---|---|---|---|
| 合规（不给建议） | 100% | **27%** | 17% | ❌ 把专业咨询师判成"否" |
| 结果（更愿意说下去） | 92% | **33%** | 8% | ❌ 同上 |
| **具体（回应了具体内容）** | 92% | **58%** | **0%** | ✅ 可用 |

新问法不含任何人设措辞，对专业人士也能给出合理分数。

**换问法之后，硬负例特异度从 83–92% 升到 100%。**
原来那条漏网的有毒正能量（「这确实挺难的，不过你已经很棒了」）现在也被判否了——
因为它确实没有回应具体内容。可靠性没变（κ 1.00，重测 12/12）。

**但它在历代人格上饱和了**：

```
p1 12/12｜p2 12/12｜p3 12/12｜p4 10/12｜p5 12/12
```

所以它只能当**下限守卫**——「这条回复是不是变通用了、掉到模板水平了」，
不能当质量阶梯用。

这跟前面的结论一致：这套工具能抓明显退化，抓不到细微提升。

### 成对判据：先过对照，再用它下结论

第一次试跑直接拿 p4 vs p5 去比，一半样本换位后答案反转。
那可能是位置偏好、也可能是判官根本没偏好，光看反转率分不出来。

于是加了两个对照，**对照不过就不许用目标组的结论**：

| 组 | 结果 | 说明 |
|---|---|---|
| 明确差异（真回复 vs 模板） | **40/40 选中真回复** | 判官认得出明显好坏，且不受位置影响 |
| 完全相同（自己 vs 自己） | **40/40 判平局** | 不会硬选一边 |
| 目标（p4 vs p5） | p4 14 : p5 7，换位不一致 10 | 计入 21 对 |

**对照全过，所以目标组的结果可以读。** 但：

* 计入的只有 21 对（40 对里 10 对换位不一致、9 对解析失败）
* p5 胜率 7/21 = 33%，95% 区间 **17%–55%，跨过 50%**
* 结论仍然是**分不出谁更好**

### 但方向值得记一笔

11 对里有 7 对判 p4（旧版）更像真人说话。虽然不显著，
但这个方向和「p5 去掉生活细节之后回复变通用了」的担心是一致的。

**这不构成「应该回退 p5」的证据**——p5 是为了解决编造生活才做的，
那是探针测出来的确定问题。它只是提示：去细节的同时可能丢了具体性。

**这个解释已经被检验过，不成立。**

于是加了 `checks/grounding.py`：量回复里的中文二元组有多少比例是用户刚说过的词
（不依赖分词）。两版各 60 条：

| 版本 | 具体性（复用用户用词） | 二段式 | 提问率 |
|---|---|---|---|
| p4-openings | **6.3%** | 23/60 | 0.38 |
| p5-nolife | **6.8%** | 26/60 | 0.25 |

**两版的具体性完全一样。** 所以「p5 变通用了」不成立 ——
那 2:1 的成对偏好大概率只是噪声（区间跨 50%）。

### 结论：不改产品

这一轮最好的产出是**否决了一个改动**。如果没有这个度量，
很可能会顺着「旧版更像真人」的印象去改人格，而那是被噪声驱动的。

### 成对判据自身也挂了（历史记录）

`run_pairwise.py` 已经写好：同一批用户发言，p4 与 p5 的回复一对一比，
**每条判两次（左右互换），只有两次指向同一方才计入**。

第一次试跑（12 对）：

```
p5 胜 2｜p4 胜 4｜平 0｜左右互换后不一致 6
```

**一半的样本在换位后给出了相反答案。** 这说明判官在这个粒度上
要么有位置偏好，要么根本没有稳定判断。

所以这轮没能回答「p4 和 p5 谁更好」，但它回答了一个更基础的问题：
**这两版在通用风格上的差别，低于现有判据的分辨力。**

唯一能分开它们的还是定向探针（编造自己的生活：p4 6/6，p5 0/6）。
这和轮次 3 的结论一致，只是现在有了三条独立证据：
L1 规则分不开、比例对比测不出、成对判据也不稳定。
